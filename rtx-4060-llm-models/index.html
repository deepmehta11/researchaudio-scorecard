What LLM can an RTX 4060 8GB run?

At the default reserve, the generic one-card floor reaches an 8B INT4, 3B INT8, or 3B FP16 tier. Named models still need artifact, context, cache, and runtime inputs.

Can an RTX 4060 run Qwen3 8B?

The INT4 planning profile reaches 5.26 GiB at 4K and 5.93 GiB at 8K. Both clear the 7.2 GiB budget, but the exact artifact and runtime still need validation.

Can an RTX 4060 run Qwen3 8B at 32K context?

Not under this conservative fully GPU-resident plan. The target reaches 9.98 GiB with a BF16 KV cache and 20 percent headroom.

Can an RTX 4060 run a 13B model?

The generic 13B INT4 weight-only target reaches 7.26 GiB, narrowly above this budget before context. Lower-bit artifacts or offload can move the line, with quality or speed tradeoffs.
